# Obsidian IMA Plugin

IMA 知识库同步插件 - 将 IMA 知识库笔记同步到 Obsidian,内置增量同步、本地缓存、限流保护、文件夹递归拉取,大幅减少 API 调用。

> **当前版本: v2.1.5** — 修复了知识库笔记内容获取的核心 bug,详见 [更新日志](#更新日志)

## 功能

### 核心同步
- 🔄 增量同步知识库(只同步本地没有的新笔记)
- 📚 全量同步知识库(刷新本地全部笔记)
- 📓 同步自己的笔记本笔记
- 🔗 同步分享链接笔记
- 📁 支持自定义保存文件夹
- 🗂️ **文件夹递归拉取**(v2.1.3+):自动递归知识库内的文件夹,拉取所有层级笔记

### API 优化(v2.0+)
- ⚡ 本地缓存:知识库列表 / 笔记本列表带 TTL 缓存,默认 30 分钟
- 🚦 请求节流:QPS 限速(默认 2 QPS),避免触发 IMA 限流
- 🔁 自动重试:429 / 网络错误指数退避重试(默认 3 次)
- 🔒 同步锁:防止重复触发同步任务
- 📊 进度条:实时显示同步进度,支持取消
- 🤖 自动同步:支持启动时自动增量同步,可配置定时周期

### 诊断工具(v2.0.2+)
- 🩺 **API 连接诊断**:3 步检测(网络 → 认证 → 业务接口),精准定位问题
- 🔍 **调试信息查看**:一键查看 API Key 状态、同步状态、缓存情况
- 🛠️ **同步锁重置**:同步卡住时强制恢复

## 安装

### 手动安装

1. 下载 `main.js`、`manifest.json`
2. 复制到 Obsidian 插件目录:
   - Windows: `<vault>/.obsidian/plugins/obsidian-ima-plugin/`
   - macOS: `~/Library/Application Support/obsidian/obsidian-ima-plugin/`
3. 重启 Obsidian 并在设置中启用插件
4. 在插件设置中配置:
   - **API Key**: 从 https://ima.qq.com/agent-interface 获取

## 使用方法

### 推荐工作流:增量同步

大多数情况下使用**增量同步**即可,它会:
1. 读取本地已同步笔记的 `media_id` / `doc_id`
2. 只对本地不存在的笔记发起 API 请求
3. 已存在的笔记直接跳过,**几乎不产生 API 调用**

触发方式:
- 点击左侧栏的刷新图标
- 命令面板执行 "增量同步知识库(推荐)"
- 设置页 "增量同步" 按钮

### 全量同步

当需要重新拉取所有笔记内容时使用(会清除列表缓存):
- 命令面板执行 "全量同步知识库"
- 设置页 "全量同步" 按钮

### 选择知识库

1. 命令面板执行 "选择知识库同步"
2. 勾选要同步的知识库
3. 选择"增量同步"或"全量同步"

### 同步笔记本

- 命令面板执行 "同步笔记本笔记"
- 勾选要同步的笔记后点击"同步选中"

### 同步分享链接

- 命令面板执行 "同步分享链接笔记"
- 粘贴分享链接或笔记 ID

## 高级配置

在设置页的"高级配置"区域可调整:

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 缓存有效期(分钟) | 30 | 列表类数据的缓存时长,过期自动重拉 |
| API 速率限制 (QPS) | 2 | 每秒最大请求数,建议保持 2 |
| 最大重试次数 | 3 | 限流/网络错误的重试次数 |
| 请求超时(毫秒) | 30000 | 单个请求超时时间 |
| 自动增量同步 | 关闭 | 启动时自动增量同步 |
| 自动同步间隔(分钟) | 0 | 0=仅启动时同步;>0=定时循环同步 |

## 缓存管理

设置页提供缓存管理:
- 查看当前缓存项数量和最早生成时间
- 清除全部缓存
- 单独清除知识库列表缓存 / 笔记本列表缓存

## 命令列表

| 命令 | 说明 |
|------|------|
| 增量同步知识库(推荐) | 只同步新笔记,API 调用最少 |
| 全量同步知识库 | 重新拉取所有笔记 |
| 选择知识库同步 | 打开选择 Modal |
| 同步分享链接笔记 | 输入链接同步单条 |
| 同步笔记本笔记 | 同步自己的笔记本 |
| 清除 API 缓存 | 立即清空所有缓存 |
| 取消正在进行的同步 | 中断当前同步任务 |
| 测试 API 连接 | 快速验证 API Key 是否有效 |
| 诊断连接 | 3 步完整诊断报告 |
| 显示调试信息 | 查看当前配置与缓存状态 |
| 重置同步锁 | 同步卡住时强制恢复 |

## 注意事项

⚠️ **权限说明**:
- 笔记 API (`get_doc_content`) 需要**笔记作者**权限
- 知识库导出 API (`export_media_for_ima_sandbox`) 需要知识库管理员权限
- 知识库笔记内容获取通过 `get_media_info` 接口,普通成员可用

⚠️ **v1 → v2 升级**:
- 配置文件向后兼容,旧设置会自动补全新增字段
- 旧版本同步的笔记文件无需迁移,增量同步会自动识别
- 建议升级后执行一次"全量同步"以重建本地索引

### 优化效果

相比 v1.0,v2.1 在典型场景下的 API 调用对比:

| 场景 | v1.0 调用量 | v2.1 调用量 | 降幅 |
|------|------------|------------|------|
| 打开"选择知识库"Modal | 全量拉取知识库列表 | 命中缓存,0 次 | 100% |
| 重复点击"全量同步" | 每次全量拉取 | 同步锁拦截,0 次 | 100% |
| 二次增量同步(无新笔记) | 全量重新拉取 | 比对本地索引,0 次 | 100% |
| 二次增量同步(10%新笔记) | 全量重新拉取 | 仅拉取 10% | 90% |
| 触发限流后 | 直接失败 | 指数退避重试,自动恢复 | — |
| 知识库含文件夹 | 只拉根目录 | 递归拉取所有层级 | 完整覆盖 |
